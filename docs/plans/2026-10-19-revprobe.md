# RevProbe Implementation Plan

**Goal:** Build an open source CLI that turns document revisions into targeted RAG freshness probes and reports stale answers.

**Architecture:** A zero dependency Python package extracts changed paragraphs from two Markdown or text snapshots. It creates reviewable probes with exact old/new anchors, optionally improves questions with an OpenAI compatible model, and checks recorded answers or an HTTP question answering endpoint. Reports include source hashes and per probe evidence.

**Tech stack:** Python 3.11+, standard library, `unittest`, GitHub Actions.

1. Implement document change extraction and deterministic probe generation; verify with fixtures.
2. Add optional model assisted question generation with strict output validation; verify using a fake transport.
3. Add response adapters and three state evaluation (`pass`, `fail`, `inconclusive`); verify stale, fresh, missing, and revision mismatch cases.
4. Add CLI and JSON/Markdown reporting; run end to end fixture demonstrations.
5. Write README, license, contribution guide, and CI workflow; run full suite and package install.
6. Publish public GitHub repository when authentication is available, then verify the remote state.
